# .app-notes/ (the project's working notes)

Everything the method produces while it works lives here, so any agent or person can pick the project up later:

- `brief.json`        what the person asked for, who it is for, what is known and what is not (claims ledger)
- `requirements.json` every thing the person said, one line each, with a status and where it is served
- `research.md`       the category study and the design thesis
- `direction/`        inspiration boards, the chosen concept, `DESIGN.md`
- `plan.md`           pages, sections, features, assets (the to-do list)
- `qa/`               the QA pictures, report and recordings (git-ignored, rebuilt every run)

Nothing here ships to visitors. See the skill's `references/00-operating-loop.md` for the formats.
